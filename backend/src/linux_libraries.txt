# The system files chaiNNer-C needs on Linux, and the package that provides each one per
# distribution family. Two programs read this table: the launcher (chaiNNer.sh), which stops
# with the install command before it starts Electron, and the backend (linux_libraries.py),
# which logs the command when OpenCV, VapourSynth or ROCm would not load.
#
# Columns: file, groups, apt, dnf, pacman, zypper.
# - A file with ".so" in its name is a library the dynamic loader must find (ldconfig -p, or a
#   directory of LD_LIBRARY_PATH); any other file is a program that must be on the PATH.
# - Groups, comma-separated: base is what the Python wheels need (OpenCV's Qt, VapourSynth's
#   plugins), electron is what the Electron binary links against, display is what the
#   command line needs to run a chain without a display, amd is what ROCm's wheels need where
#   PyTorch may run on an AMD GPU: the AMD kernel driver's compute interface is there
#   (/sys/class/kfd/kfd/topology/nodes) and no NVIDIA driver is (/proc/driver/nvidia; with one,
#   PyTorch runs on CUDA). The launcher only prints amd's install command: a machine whose AMD
#   GPU never runs models starts without them.
# - "(t64)" after an apt name: Debian 13 and Ubuntu 24.04 (glibc 2.38 and newer) renamed the
#   package with a t64 suffix there (libasound2t64), and no longer have the old name.
